# Экспорт юнит-экономики для ИИ

Исходный файл: `unit_economy_Dai_774_mond_oktyabr_33__33.xlsx`

## Как использовать
- Этот файл содержит все непустые ячейки обоих листов, включая исходные формулы Excel и сохранённые результаты формул.
- Для сайта формулы нужно реализовать в коде (JavaScript/TypeScript или на сервере), а не рассчитывать на выполнение формул Excel внутри JSON/Markdown.
- `Кэш` — результат, сохранённый в исходном Excel на момент последнего пересчёта; он может быть устаревшим.
- Ссылки вида `Тарифы!$B$12` означают связь между листами; при реализации нужно сохранить эти зависимости.

## Важные замечания, обнаруженные в файле
- В листе `UNIT по товарам` есть формула с `#REF!` в итоговой ячейке `U17`; её нужно восстановить по бизнес-логике перед использованием на сайте.
- В `V17` сохранён результат ошибки `#VALUE!`; формулу и типы данных следует проверить.
- Некоторые строки товаров (например, строки 15–16) содержат формулы, но не заполнены исходными данными; сайт должен корректно обрабатывать пустые поля.
- Ячейка `G14` листа `UNIT по товарам` хранит `0.07` как текст, а не число; при переносе следует нормализовать тип данных.
